# Blink Demo in Swift using RGB LED (WS2812)

Simple Wendy Lite native app written in Swift

### Swift compiler

To compile and run this app, you need a Swift toolchain with Embedded Swift support. Confirm the installation by running `swift --version`; it should report version “6.3.3” or above.

### Supported boards

* ESP32-C6-DevKitC-1
* ESP32-C6-DevKitM-1
* ESP32-C61-DevKitC-1
